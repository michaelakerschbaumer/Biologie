# Neuro Lernwelt

Interaktive Lernumgebung zur Neurobiologie mit sechs Themen, 68 Quizfragen, Karteikarten, Fehlerwiederholung und einem Prüfungsmodus. Die Seite funktioniert ohne Server und ohne Anmeldung. Der Lernfortschritt bleibt im jeweiligen Browser. Offene Antworten werden anhand einer Musterlösung selbst bewertet.

## Auf GitHub Pages veröffentlichen

1. Ein neues öffentliches Repository anlegen, zum Beispiel `neuro-lernwelt`.
2. Alle Dateien dieses Ordners in das Hauptverzeichnis des Repositorys hochladen. `index.html` muss direkt dort liegen.
3. Unter **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch** auswählen.
4. Als Branch **main** und als Ordner **/ (root)** auswählen und speichern.
5. Nach der Bereitstellung zeigt GitHub dort den Link zur Website an. Diesen Link kannst du am Handy öffnen und teilen.

Dokumentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Lokal öffnen

`index.html` im Browser öffnen. Die Schriftarten werden optional über Google Fonts geladen; ohne Internet werden Systemschriften verwendet.

Die Veröffentlichung enthält ausschließlich die Lernumgebung, keine Originalfotos, persönlichen Abgaben oder Zugangsdaten.
